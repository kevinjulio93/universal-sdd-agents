# Frontend Procedure

Inspect existing components, design tokens, state/data flow and API contracts.
Preserve the established visual language and framework patterns. Cover responsive
layout, keyboard/focus behavior, semantic labels and loading/empty/error states.
Handle stale responses, cancellation and retry without duplicating side effects.
Never expose provider credentials or trust model-rendered content as safe HTML.
Add assigned component/regression tests and propose browser checks to orchestrator.
Edit only assigned baseline-captured paths. No shell, check execution, delegation,
contract redesign or self-approval; report blockers through orchestrator.
