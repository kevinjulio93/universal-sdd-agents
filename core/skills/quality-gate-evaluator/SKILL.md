# Evaluation procedure

Consult references/evidence-contract.md when interpreting machine results. Verify
run/scope identity, executed checks, baseline comparisons and non-applicability.
Challenge stale coverage and unproven debt classification. Audit reviews and active
acceptance before G5. No arbitrary numeric scores or inferred success.
Use only project-configured thresholds/tools; Sonar is not universally required.
Ask orchestrator for missing checks/artifacts. Read-only: no edits, shell, check
execution, delegation or writing release evidence on behalf of another reviewer.
